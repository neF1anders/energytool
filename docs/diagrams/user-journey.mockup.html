Путь клиента: от сайта до брифа менеджеру

Вместо формы «Заказать консультацию» клиент сразу попадает в диалог. Бот ведёт к продукту и по ходу заполняет фиксированный контракт (опросный лист по продукту). Менеджер получает бриф и звонит уже с расчётом, а не с вопросом «какие у вас счётчики».

1. Путь по шагам

Строки — кто действует, столбцы — этапы. Шаги 3–4 повторяются, пока не закрыты обязательные поля.

3. Контракт: что собираем

Общий блок плюс блок на каждый продукт. Бот спрашивает поля только тех продуктов, что в лидерах. * — нужно для готовности.

Общий блок

  • Сегмент: МСБ / предприятие / СНТ, УК / сеть *
  • Боль своими словами *
  • Регион *
  • Число объектов / точек учёта
  • ФИО, телефон, компания *
  • Согласие на обработку ПДн *

Выход на оптовый рынок по опросному листу, 16 п.

  • п.3 Макс. мощность по документам ТП, МВт *
  • п.2 Регион(ы) *
  • п.5 Текущий сбыт / гарантирующий поставщик *
  • п.7 Точек поставки / измерения, есть ли субабоненты
  • п.9 Система учёта: сервер, ПО, типы ПУ, каналы связи
  • п.6 Отдельный договор на передачу: да / нет
  • п.15 Ценовая категория · п.16 График работы
  • п.13 Потребление за год помесячно · п.14 почасовые профили
  • п.4, 8, 10, 11 Документы (акт ТП, однолинейная схема, поверка, акты допуска): есть / нет / уточню
  • п.1 Название, ИНН · п.12 Контакт — в конце

Документы бот не собирает, а отмечает наличие: это и есть список «что подготовить к звонку».

Платформа учёта (облачная АСКУЭ)

  • Число приборов учёта *
  • Типы и марки ПУ * (менеджер просил именно это)
  • Связь: есть / нет, чья SIM
  • Как снимают показания сейчас
  • Цель: техучёт по цехам / биллинг абонентов / управление нагрузкой

Фото-показания

  • Сколько точек и кто снимает *
  • Канал сейчас (мессенджер, бумага)
  • Почему нельзя поставить счётчик со связью (аренда и т. п.)

Солнечная станция (сетевая / гибридная)

  • Тип и площадь кровли или площадки *
  • Ориентация, тень
  • Дневная доля потребления *
  • Отключения (довод за гибрид с накопителем)

Поиск коммерческих потерь

  • Тип организации: сеть / сбыт *
  • Число абонентов / приборов *
  • Есть ли данные приборов в цифре

Для потребителей бот отсекает этот продукт, как сделал менеджер.

Источники полей: «Опросный лист ОРЭМ» от менеджера и раздел базы 00-reference/03-calculation-and-requests («Какие сведения могут понадобиться» по каждому продукту). Для платформы учёта менеджер отдельно просит типы и марки ПУ.

4. Что получает менеджер

Детерминированный рендер из состояния, не пересказ диалога моделью. Текст для человека, JSON для CRM.

ЗАЯВКА · ООО «Тихорецкий хлебный двор» · Иван
Сегмент: производство (хлебозавод + склад + 3 магазина)
Боль: счета +18% за год при росте объёма +4%

Кандидаты
 1. Выход на ОРЭМ — 1 100 кВт (порог пройден),
    420 тыс. кВт·ч/мес — ниже ориентира 1 млн → пограничный
 2. Сетевая СЭС — склад, профлист 2 400 м², юг,
    дневная нагрузка (холодильник)
 3. Платформа учёта — 6 техсчётчиков в Excel
    (упомянуто, не обсуждали)

Не хватает: ценовая категория, однолинейная схема,
